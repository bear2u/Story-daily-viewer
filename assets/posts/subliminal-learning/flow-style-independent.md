# 흐름·설명·문체 독립 검토

검토 대상: `report.md`의 22파트. `rubric.md`와 `style-guide.md`의 기준을 적용했음. 원장·논문·outline은 보지 않았으므로 사실 검증이나 정확성 채점은 하지 않음. 원고를 수정하지 않았고, 아래 수정안은 숫자·날짜·고유명사와 서법을 바꾸지 않는 국소 윤문 제안임.

## 비약·용어·설명

| 파트 | 문장 | 무엇이 문제인가 / 고칠 방향 |
|---|---|---|
| 3–4 | ‘스승이 어떤 답을 골랐는지 배움.’ / ‘학생은 그 숫자 답안을 학습함.’ | 쉽게 설명한 줄만 읽으면 학습이 예시를 대화창에 넣는 일인지, 학생 모델 내부를 바꾸는 일인지 아직 구별하기 어려움. 4에서 문맥 학습과 구별하지만 ‘이 실험에서는 무엇이 바뀌었는가’는 말하지 않음. 실제 학생 학습에서 바꾸는 대상을 한 줄로 원장 확인 후 덧붙이면 좋음. |
| 6 | ‘랭크 8 LoRA를 붙이고 Adam으로 학습함. / LoRA는 기존 가중치에 작은 저랭크 갱신을 더함.’ | LoRA의 이름과 숫자가 설명보다 앞섬. ‘저랭크 갱신’은 처음 보는 사람에게 ‘랭크 8’의 뜻을 풀어주지 못함. 기존 가중치는 두고 추가 부분을 학습하는 장면을 먼저 쓰고 이름·수치·정확한 조건을 뒤에 두기. ‘쉽게 말하면/정확히는’ 짝도 없음. |
| 6 | ‘전체 층의 지정 가중치’ / ‘다섯 시드 결과’ | 층·가중치·시드가 설명 없이 첫 등장함. 시드는 서로 다른 무작위 출발 조건이라는 짧은 설명으로 충분함. 층·가중치는 뒤의 앞쪽 층 동결까지 연결되는 핵심이므로 실제 모델 내부 역할을 한 줄로 풀 필요가 있음. Adam까지 자세히 풀 필요는 낮음. |
| 7 | ‘많은 샘플에 낮은 확률 후보도 섞이면 / 스승의 확률분포를 간접적으로 알 수 있음.’ | 왜 여러 답만으로 확률표를 알 수 있는지 초심자는 한 번 더 묻게 됨. 후보가 얼마나 자주 나오는지에서 확률을 추정한다는 중간 걸음이 빠져 있음. 이 한 줄을 넣으면 3의 ‘확률표 없이 출력만’ 질문도 더 잘 회수됨. |
| 8 | ‘얽힘이 강한 상위 50개 숫자를 포함한’ | ‘얽힘이 강함’을 어떻게 읽어야 하는지 없어 그림의 숫자 제거 조건이 갑자기 등장함. 앞 파트의 동물 취향과 숫자 예측 확률이 함께 달라지는 관계를 받아서 써주기. 측정법을 설명한다면 원장 확인 필요. |
| 9 | ‘정확히는 사실 스승이 만든 동일 접두 문맥에서’ | ‘사실 스승’이 처음 등장하는데 뜻이 없음. ‘사실’이 부사인지 특정 교사의 이름인지도 모호함. ‘동일 접두 문맥’도 바로 위의 ‘앞에서 본 숫자 문맥’보다 어렵게 바뀜. 실제 비교의 기준 스승이 누구인지 원장 확인 후 명시하고, 접두는 이미 나온 숫자 조각까지의 문맥이라는 설명으로 풀기. |
| 10 | ‘한쪽은 분기 토큰 위치의 오차만 줄임.’ / ‘같은 답안에서 채점하는 위치를 바꾼 셈임.’ | 손실 마스킹의 직관 자체는 잘 전달됨. 다만 학습 오차를 줄인다는 것이 학생의 예측이 답안과 다른 정도를 줄이는 일임은 아직 없음. 쉽게 설명한 줄에 ‘어느 위치의 틀린 예측을 고칠지’까지 넣으면 더 명확함. 정확히는의 ‘마스킹한 토큰도 앞 문맥으로 남김’은 삭제와 구별하는 좋은 조건 설명임. |
| 11 | ‘강한 가정에 기대는 설명이며’ | 무슨 가정인지 없어 독자가 수학적 직관의 범위를 판단할 재료는 얻지 못함. 본문에서 수학을 설명하지 않을 계획이라면 이 짧은 주의만 남겨도 되지만, 전문성 재료로 계산한다면 가정의 성격 하나를 원장 확인 후 풀 필요가 있음. |
| 12 | ‘내부 활성값을 바꿨을 때의 영향을 조사함.’ | 내부 활성값이 모델이 계산하는 중간 결과라는 설명이 없음. 뒤의 19에서 벡터·성분 조작으로 다시 등장하므로 여기서 한 번 풀면 두 파트가 연결됨. |
| 17 | ‘정렬 점수 30 미만을 부정렬로 분류했고 / 일관성 점수 50 미만 답변은 제외함.’ | 숫자 기준은 분명하나 정렬 점수·일관성 점수가 각각 답변의 무엇을 재는지 없음. ‘부정렬’ 역시 동물 취향 변화와 달리 안전 평가의 이름이므로 행동 예시나 판정 대상을 먼저 풀 필요가 있음. |
| 19 | ‘그 방향이 정렬되는 결과’ / ‘해당 성분을 기준 모델 성분으로 바꾸자’ | 방향의 정렬과 성분 교체가 추상적으로만 남음. 앞의 ‘벡터를 더하면 출력 행동이 바뀜’은 도움이 되지만, 스승과 학생 내부 변화가 비슷한 방향이라는 의미를 일상어로 먼저 말하면 읽힘. 핵심 개념의 쉽게/정확히 짝도 없음. |
| 20 | ‘LoRA Artifact라는 다른 반박 논문’ | 처음 나온 제목만으로 무엇을 반박했는지 알 수 없음. ‘다른’이 어떤 기존 반박과 구별하는지도 불분명함. 바로 뒤의 ‘LoRA에서만 일어난다거나 전체 미세조정이면 사라진다’와 관련된 논쟁임을 먼저 밝혀주기. 공지에 없는 세부 철회 대상을 추정해서 넣으면 안 됨. |

괄호에 설명을 밀어 넣은 문제는 없음. 그림 캡션의 Figure·Table·저자 표기는 정보 표기라 지적 대상이 아님. ‘킬포’·‘반전’ 같은 밑밥 없는 라벨도 없음.

## 쉬운 설명만 읽을 때

| 개념 | 판정 | 이유 |
|---|---|---|
| 지식 증류 | 부분적으로 이해 가능 | 스승 답을 학생이 배운다는 관계와 확률표 없이 답만 배우는 이번 연구의 질문은 보임. 다만 학생의 ‘배움’이 모델을 바꾸는 훈련이라는 장면과, 답마다 매긴 확률이 무엇인지는 더 풀어야 문맥 학습과 확실히 구별됨. |
| LoRA | 부족 | ‘쉽게 말하면’ 줄이 없고 유일한 정의가 ‘작은 저랭크 갱신’임. 이 상태로는 앞쪽 층만 LoRA 학습하는 실험의 의미까지 따라가기 어려움. 기존 가중치와 추가 학습 부분의 관계를 먼저 설명할 필요가 큼. |
| 손실 마스킹 | 대체로 이해 가능 | ‘같은 답안에서 채점하는 위치를 바꾼 셈’이 분기만 학습/나머지만 학습을 잘 이어줌. 틀린 예측을 고치는 위치를 선택한다는 한 줄을 더하면 ‘채점’과 실제 학습의 연결까지 잡힘. |

## 밑밥·회수와 마무리

- 도입의 ‘숫자 어디에 남은 걸까 / 숫자의 뜻부터 찾으면 풀릴까’는 9–11의 문맥별 분기 정의와 21의 숨은 뜻을 독해했다는 설명이 필요 없다는 답으로 회수됨.
- 3의 ‘확률표 없이 출력만 줘도 옮겨갈까’는 4에서 현상을, 7–8에서 분포 누출 가설의 필요성을 확인하므로 회수됨.
- 9의 ‘분기만 배웠을 때’는 10에서, 12의 앞쪽 동결은 13에서, 14의 과제 성능 질문은 15에서 바로 회수됨.
- 회수되지 않은 명시적 밑밥은 없음. 11의 수학적 직관은 추가 설명 예고라기보다 소개 후 범위 제한임. 다만 독자는 왜 가정이 강한지는 알 수 없음.
- 마지막 두 파트는 도입으로 돌아와 답하고, 현재 공개 상태·남은 검증 범위도 보여줌. 3줄 요약의 주어와 조건도 대체로 분명함.
- 다만 실제 파일의 맨 끝은 3줄 요약이 아니라 참고 링크임. ‘3줄 요약으로 닫힘’ 기준을 지키려면 관련 링크를 요약 앞에 두는 작은 배치 수정이 필요함.

## AI 문체 국소 제안

의도된 음슴체·짧은 줄바꿈·구어는 지적하지 않음. 가장 눈에 띈 12곳만 골랐음. 사실 내용 삭제 여부는 집필자가 판단할 사항이며, 유보와 인용 귀속은 유지해야 함.

| 파트 | 원문 줄 | 패턴 | 수정안 (줄바꿈은 /) |
|---|---|---|---|
| 5 | ‘같은 현상을 이어 조사한 관계는 확인됨. / 그 이상으로 연구 동기를 추측할 필요는 없음.’ | 사실 뒤에 붙은 저자의 검토 메타 멘트. 이미 전작 조사와 감사 관계가 제시됨. | ‘같은 현상을 이어 조사한 관계는 확인됨.’까지만 두기. |
| 6 | ‘그 갱신을 학습한 조건임.’ | 바로 앞 LoRA 정의를 다시 결산하는 설명형 줄. | ‘LoRA는 기존 가중치에 작은 저랭크 갱신을 더하고 / 그 갱신을 학습함.’ |
| 9 | ‘한쪽은 다음 숫자 조각을 이렇게 고르고 / 다른 쪽은 다른 조각을 고르는 위치가 있음.’ | ‘이렇게/다른’이 구체적 장면 없이 대비만 매끈하게 만듦. | ‘같은 문맥인데 / 두 스승이 다음 숫자 조각을 다르게 고르는 위치가 있음.’ |
| 11 | ‘여기부터는 학습 조건을 조금 더 따져보는 파트임.’ | 파트 역할을 설명하는 예고 멘트. 다음 줄이 이미 조건을 풀어줌. | 삭제하고 ‘분기는 특정 숫자 자체의 꼬리표가 아님.’으로 바로 잇기. |
| 13 | ‘취향 전달을 줄이는 것과 / 어떤 능력을 지켰는지는 따로 봐야 함.’ | 바로 앞 훈련 재현/새 숫자 성능의 구별을 추상 문장으로 다시 결산함. | 앞의 구체적인 두 성능 설명을 남기고 이 두 줄 삭제하기. |
| 15 | ‘이 방법은 확인한 설정에서의 억제 수단임. / 안전 보장으로 읽을 범위는 아님.’ | 연속해서 나오는 주의형 대구. 의미는 필요하나 표현을 묶을 수 있음. | ‘확인한 설정에서 전달을 줄였지만 / 안전을 보장하는 결과는 아님.’ |
| 17 | ‘여기부터는 안전 평가 조건을 보는 파트임.’ | 11과 같은 파트 역할 예고. 앞뒤에서 평가법이 다름을 이미 말함. | 삭제하고 위험한 금융 조언 스승 설명으로 바로 잇기. |
| 18 | ‘같은 재표현이라는 말로 묶어도 조작이 다름.’ | 앞의 입력/출력 대비 뒤 결산 줄. | ‘입력을 바꾼 실험과 / 출력을 바꾼 실험임.’ 또는 앞의 구체적 대비가 충분하면 삭제. |
| 18 | ‘입력·출력의 표면만으로는 답이 다 안 나옴.’ | 다음 파트로 넘기는 추상적인 매끈한 예고. 무엇이 남았는지 불분명함. | 이 줄을 빼고 19 첫 줄에서 내부 변화 후속작을 바로 시작하기. |
| 20 | ‘논문 제목만 이어 붙이면 / 진행 중인 논쟁이 끝난 것처럼 보일 수 있음.’ | 독자에게 글의 편집 원칙을 설명하는 결산 멘트. | ‘진행 중인 논쟁이라 / 이 공지만으로 결론을 정할 수는 없음.’ |
| 21 | ‘따로 확인해야 한다는 의문이 남음.’ | 해야 한다는 의무를 ‘의문’이라 부르는 추상 결산. | ‘내용이 말끔한지와 / 학습 뒤 행동이 어떤지는 / 따로 확인해야 함.’ |
| 22 | ‘숫자 답안에 동물 이름이 없던 장면을 / 기억해둘 만함.’ | 도입을 한 번 이미 회수한 뒤 다시 회상을 권하는 정리 멘트. | ‘숫자 답안에는 동물 이름이 없었음.’으로 곧바로 장면을 다시 쓰기. |

전체 인상: 구어와 리듬은 대체로 자연스럽고, 대구를 기계적으로 반복하거나 과장하는 원고는 아님.
다만 파트의 역할을 설명하는 예고와 조건을 추상적으로 다시 결산하는 줄이 몇 군데 남았음.
윤문보다 먼저 LoRA·사실 스승·부정렬 판정·활성 방향의 설명 빈칸을 메우는 편이 독자 이해에 더 도움 됨.
