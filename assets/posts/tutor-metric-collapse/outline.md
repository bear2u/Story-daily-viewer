# 기획서
## 판단
- 유형: 발견형. 초록의 첫 질문은 지표 최적화가 수업 품질을 개선하는가.
- 날짜 기준: arXiv 최초 공개, 2026-10-08 UTC. 기준일2026-10-14.
- 독자 친숙도: AI가 수업 계획 만든다는 것은 친숙, PAI와 LoRA는 생소함.
- 도입 질문: 교육 점수를 올린 AI가 왜 더 낮은 수업 평가를 받았을까?
- 마지막 답: 고정 학습자 조건에서 매 활동을 독립 평균하면 선택 반복이 최고점에 포함됨. 인간평가 감소를 반복 하나만으로 설명할 수는 없음.
- 맺음: 코드 공개와 프리프린트 확인일, 반복연습 장면을 다시 꺼내 실제 교육과정·학생변화 검증으로 닫음.
- 기대 vs 결과: PAI .05→.42, 인간평가4.46→3.03. 실제 학생 성취도 아님.

## 밑밥과 회수
- 좋은 도움도 나중엔 줄여야 하는 예시(2)→고정 학습자 최고점 반복(5), 재채점(15)
- 선택을 채점하고 설명은 제외(4)→설명문도 바뀐 인간평가 혼동(10)
- 전체 평균은 높아짐(9)→DP2는 낮아짐(12)
## 재료
- 재미: 점수와 평가 반대, 모든 새 사례에 반복연습, 748/750문구 암기, 점수표에 없는 단계 단서.
- 전문성: PAI 분모, 모델 전환, 데이터 분리, 교사표본 정체, 가중치 분석 한계, 학습횟수·rank confound.
- 결정적 증거: Qwen 전후 행동 반복 F23–25. 인간평가 인과대조군 부재 F31.
- 구체 예시: 학습계획5활동, 동일 선택을 반복한 간단 점수 예시는 설명용임 명시.
- 전문가용 파트: 13 가중치. LoRA 정의 먼저.
- 비약 지점: 독립 평균→반복 최적해 조건을 직접 계산. 업데이트 에너지→해석은 증명이 아님 명시.
- 뺀 것: 같은 저자 전작 본문 미확보, 수치·그림 제외. 실제 학습 성과 미측정. 후속 수·독립재현 없음 단정 제외.
