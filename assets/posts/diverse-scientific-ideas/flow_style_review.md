# 독립 흐름·AI 문체 검토

검토 범위: `report.md` 본문과 `style-guide.md` 4절. 원장·원문·outline은 읽지 않았음. 본문은 수정하지 않았음. 아래는 처음 읽는 독자의 이해 흐름과 국소 윤문 제안이며 사실 검증 결과가 아님.

## 1. 20파트 경계

구분선 기준 20파트임. 아래 표는 각 파트의 진입 경계를 판정함. 실제 파트 사이 경계는 19곳이며, 1행은 도입 자체를 평가함.

| 파트·줄 | 진입 경계 | 이유·수정 방향 |
|---|---|---|
| 1. 도입, 1–17 | 좋음 | 세 개의 아이디어가 세 개의 기회인가라는 질문이 즉시 서고, 연구 목표가 이어짐. 도입 질문은 끝에서 다시 답함. |
| 2. 세트 보상 개요, 21–36 | 좋음 | 도입의 ‘세 개’를 그대로 받아 한 출력에서 세 개를 만드는 설정으로 넘어감. 곱셈 예시로 세트 기여를 먼저 보여줌. |
| 3. 입력·출력 카드, 40–55 | 좋음 | 보상을 보기 전에 무엇을 읽고 쓰는지 확인하는 이동이 자연스러움. 다만 마지막의 학습 영역·평가 규모는 다음 선행 연구 파트로 이어지지 않고 잠시 매달림. 이 두 줄을 결과 파트로 보내는 편이 매끈함. |
| 4. CREATE·DARLING, 59–75 | 약함 | 직전에는 입력 카드·데이터 규모를 읽었는데 갑자기 ‘가치를 재던 사람’이 나옴. 2파트의 보상 얘기를 독자가 다시 꺼내야 함. 첫 문장에 Manya Wadhwa와 CREATE를 바로 놓으면 인물·계보로 이동하는 이유가 분명해짐. |
| 5. 보상 수식, 79–95 | 좋음 | DARLING과 이번 방법의 차이를 말한 다음, 이번 방법의 실제 계산으로 들어감. 79–80은 2파트와 같은 판정을 한 번 더 예고하므로 삭제해도 연결이 유지됨. |
| 6. 품질 심사·평가 집계, 99–117 | 약함 | 수식의 ‘품질’을 풀어주는 진입은 좋음. 그러나 ‘지표가 궁금하면 읽으면 됨’ 이후 심사 모델 네 이름·탐욕적 순서·인내 할인·길이 보정이 한꺼번에 나옴. 앞부분의 품질 정의는 필수이고 마지막 집계 세부만 보조 정보임. 두 층을 구분해야 함. |
| 7. 학습 절차, 121–140 | 좋음 | ‘그 보상을 주기 전에’가 앞의 보상을 받아 학습 순서를 되짚음. 탐색문을 나중에 만든 자료라는 점도 think 결과를 읽을 밑밥이 됨. 단, 빈 think 블록 버전의 이름 no-think를 이곳에서 붙이면 9파트의 첫 등장이 덜 갑작스러움. |
| 8. 프롬프트 대조, 144–159 | 좋음 | 학습 설명을 읽은 독자가 할 질문을 그대로 던짐. 다양성 상승과 품질 하락을 함께 제시해 다음 학습 결과의 필요성이 생김. |
| 9. 주결과, 163–180 | 좋음 | 같은 세트 생성 조건에서 학습 효과를 보므로 비교축이 이어짐. no-think의 이름만 7파트에서 미리 붙이면 됨. Impact-only는 다음 문단에서 설명되지만 그림 안내에 ‘품질만 보상한’도 함께 붙이면 되돌아 읽지 않아도 됨. |
| 10. think 비교, 184–201 | 좋음 | 바로 전 표에서 다른 행을 보는 이동이 명확함. 출처 점수는 다음 파트의 질문으로 회수되므로 의도적인 한 파트 유예로 읽힘. ‘예상과는 다른 결과’는 앞에 그런 기대를 세운 적은 없으므로 판정 없이 수치 비교만 두어도 됨. |
| 11. 출처 의존성, 205–224 | 좋음 | 직전의 0.81을 정확도 81%로 오해할 가능성을 바로 풀어줌. 원본 문서를 받지 않는다는 제약까지 이어져 경계가 잘 작동함. |
| 12. 세트 바깥의 다양성, 228–244 | 좋음 | 출처 문제 다음에 다양성 자체의 범위를 좁혀 봄. ‘세트 안 세 답’과 ‘수많은 세트’의 대비가 구체적이어서 새 평가가 필요한 이유를 이해할 수 있음. |
| 13. 사람 평가, 248–265 | 좋음 | 자동 점수에서 실제 사람이 고르는 장면으로 전환함. 다만 ‘그 세트’는 특정 세트가 아니라 제안 모델이 내는 세트라는 정도로 읽히므로 큰 혼동은 없음. |
| 14. 실행 시험 설정, 269–284 | 좋음 | 사람이 유망하다고 고르는 것과 실제 실행을 분리하는 이동이 자연스러움. 첫 줄 ‘좋아 보인다는 다음에는’만 한국어가 걸림. ‘고정된 아이디어’는 무엇을 고정했는지 본문만으로 명확하지 않음. |
| 15. 실행 시험 수치, 288–303 | 약함 | 자원 제한 뒤 결과 비율로 가는 순서는 좋지만, 핵심 판정명 supports의 뜻을 아직 모르는 상태에서 27%·33%·29%를 읽게 됨. 판정의 최소 뜻을 수치 전에 붙이고, 그 뜻이 과학적 확증이 아니라는 구체화는 다음 파트에 남길 것. |
| 16. supports 사례, 307–322 | 좋음 | 자체 보고라는 직전 유보를 메모리 벤치마크 사례로 좁혀 보여줌. 다만 검사 설계가 구체적으로 어떻게 바뀌었는지는 본문에 없고 그림에 맡김. ‘그 아래 문장’의 아래가 무엇을 가리키는지도 약간 모호함. |
| 17. DARLING 비교 조건, 326–342 | 약함 | 실행 사례를 읽다가 학습 방법 비교로 되돌아감. ‘어느 방법이 나은지’가 실행 결과 비교인지 CU 비교인지 처음에는 불명확함. 첫 문장에서 DARLING과 CU 비교로 돌아간다고 명시하면 연결됨. |
| 18. 계보·저자, 346–365 | 끊김 | 앞 파트의 비교 조건이 마무리된 뒤, 전체 여정을 결산하고 GIANTS·SciJudge·저자 명단이 나옴. 새 핵심 이유 없이 이야기가 재시작되는 느낌임. GIANTS는 3파트의 숨겨 둔 후속 논문, SciJudge는 6파트의 품질 심사 설명에 붙이면 이미 본 대상을 설명하게 됨. 저자·소속은 도입이나 말미 자료 정보에 모으는 방향이 좋음. |
| 19. 질문 회수·남은 일, 369–382 | 약함 | ‘처음의 세 기회’로 돌아가므로 결론 자체는 이해됨. 그러나 바로 앞의 저자 명단에서 논증으로 복귀하는 경계가 약함. 18파트를 옮기면 17파트의 조건부 결론 다음에 이 답이 바로 붙어 좋아짐. |
| 20. 현재 상태·출처·요약, 386–404 | 좋음 | 결론 뒤 조사 시점과 재현 여부를 별도로 밝히는 구성은 적절함. 다만 라이선스 뒤 3줄 요약이 다시 결론을 열어 마지막 호흡이 두 번 끝남. 요약이 반드시 필요하면 출처·라이선스보다 앞에 두는 편이 읽기 흐름상 자연스러움. |

### 빠짐·비약·라벨 점검

- 예고 미회수: 큰 미회수는 없음. 숨겨 둔 후속 아이디어는 6파트 품질 심사에서, think 자료는 10파트에서, 출처 점수는 11파트에서, DARLING은 17파트에서 돌아옴. 다만 3파트 마지막의 영역·규모 정보는 뒤의 결과와 거리가 멀어 회수 체감이 약함.
- 무설명 용어: 115–117의 ‘탐욕적으로’, ‘인내 할인’, ‘길이 보정’이 가장 밀집됨. 할인은 뒤쪽 답의 기여를 줄이는지 등 작동 방향을 본문 안에서 풀어야 함. ‘길이 보정’은 8파트의 품질 하락을 읽는 데 다시 필요함. GRPO는 강화학습 방식 이름으로 역할은 주어져 있어 그보다 덜 급함. 251의 NLP, 352의 target 풀도 한국어 뜻을 먼저 주는 편이 좋음. 용어 설명은 원문 확인 가능한 담당자가 채울 것.
- supports: 15파트 수치의 해석에 꼭 필요한데 16파트까지 미뤄짐. 15파트에 짧은 판정 설명이 먼저 필요함. 정확한 번역은 이 검토에서 원문을 보지 않았으므로 확정하지 않음.
- 비약: 321–322는 ‘서로 다른 답을 더 많이 얻는 일’까지 여전히 남았다고 읽힐 수 있음. 앞에서 확인한 성과와 남은 검증을 분리해 ‘서로 다른 답을 얻어도 / 그 답이 맞는지 확인하는 일은 남았음’으로 좁히면 뜻이 선명함.
- 괄호로 설명 때우기: 본문에는 해당 없음. `지도 미세조정(SFT)`은 약칭 표기라 문제 아님. 그림 설명의 Proposed·숫자 안내도 설명 본문을 대체하는 긴 괄호가 아님.
- 밑밥 없는 라벨: ‘오히려’(242)는 앞에서 세트 내 거리 상승을 봤으므로 근거가 있음. ‘예상과는 다른 결과’(188–189)는 기대를 미리 세우지는 않았음. ‘이 짧은 문구가 조건을 바꿈’(334)은 어떤 조건인지 한 줄 늦춰 말하는 예고형 라벨임.
- 마지막 답·현재·앞으로: 모두 있음. 답은 ‘서로 다른 방향을 고르는 효과는 보였지만 발견 세 개의 확증은 아니다’, 현재는 심사 중·독립 재현/정식 채택 미확인·해설자의 학습 재실행 없음, 앞으로는 출처 의존성과 여러 세트의 탐색 폭을 함께 지키는 과제임. 다만 도입 질문은 ‘실험 기회’이고 결론 부정은 ‘입증된 발견’이라 잣대가 한 번 바뀜. 결론에 ‘선택지는 늘었지만 세 번의 독립적인 성공 기회를 입증한 시험은 아님’처럼 질문의 단위로 직접 답하는 방향을 권함. 이 표현의 사실 적합성은 원장 담당 확인이 필요함.

## 2. AI 문체 국소 수정 제안

의도적인 음슴체·짧은 줄바꿈·‘근데’·‘임’ 자체는 지적하지 않음. 4절의 빼기 전용·국소 수정 원칙을 적용함. 숫자·날짜·고유명사·유보는 변경하지 않았으며 새 비유를 넣지 않았음. 아래 14곳은 전부 적용할 필요 없이 해당 부분의 중복과 예고를 덜어내는 후보임.

| 위치 | 걸리는 패턴 | 국소 수정안 |
|---|---|---|
| 59–60 | 인물 소개를 미루는 분열형 문장·설명형 종결 | 앞의 두 줄을 지우고 `제1저자 Manya Wadhwa가 함께 쓴`으로 바로 시작. CREATE 설명 뒤에 `이번엔 그 값으로 모델을 훈련했음`을 둘 수 있음. |
| 79–80 | 앞에서 한 판정을 재예고함 | 두 줄 삭제. `쉽게 말하면`부터 시작해도 직전의 방법 차이와 연결됨. |
| 101 | 본문 밖의 독서 안내·예고 | `여기는 지표가 궁금하면 읽으면 됨` 삭제. 품질의 뜻은 뒤 결과 해석에 필요하므로 선택 정보로 보이지 않게 함. |
| 139–140 | 부정 대구를 덧붙여 같은 사실을 다시 말함 | `실제 보상에는 형식 보너스와 길이 벌점도 있음`만 남김. 핵심 곱셈만은 아니라는 뜻이 이미 포함됨. |
| 179–180 | 추상적인 결산 문장 | `보상이 개별 답의 품질뿐 아니라 / 세트 안의 겹침도 따지게 됨`으로 직접 서술. |
| 188–189 | 숫자를 읽은 뒤 반전을 다시 선언함 | 두 줄 삭제. `다만 여기선 사후 합성한 탐색문을 배웠음`은 유지해 해석 제한을 바로 붙임. |
| 223–224 | ‘축’으로 추상화한 설명형 마무리 | `no-think는 강화학습 전 0.90에서 0.61로 내려감 / CU가 오르는 동안 출처 의존성은 내려감`으로 구체 명사를 유지. |
| 269–270 | 명사화가 겹친 어색한 연결 | `좋아 보인 다음에는 / 실제로 시험할 수 있느냐가 남음`으로 ‘다는’만 덜어냄. |
| 307–308 | 사례를 보여주기 전 의미를 예고함 | 두 줄 삭제하고 `부록에는 AI 메모리를 시험하는`부터 사례로 시작. |
| 319–320 | 대구에 설명형 종결이 겹침 | `벤치마크를 만들어볼 가치는 있지만 / 그 가설이 확립된 건 아님`으로 줄임. 확립되지 않았다는 유보는 그대로 남음. |
| 326–328 | 모호한 전환+선택 독서 안내 | `앞에서 나온 DARLING 재구현은 / 학습 출발 조건도 달랐음`으로 진입한 뒤 기존 CU 수치를 유지. ‘궁금할 때 읽으면 됨’은 삭제. |
| 334 | 사실을 미루는 극적 예고 | `부록에는 SFT 출발 조건이 적혀 있음`으로 구체화. |
| 346–348 | 여정 결산 뒤 새로운 설명을 여는 정리 멘트 | 세 줄 삭제하고 `GIANTS는 실제 후속 논문의 통찰을`부터 바로 시작. 계보의 위치 이동 여부는 흐름 검토 표 참조. |
| 369 | 공식적인 ‘처음으로 돌아가면’ 결산 | `처음의 세 기회로 돌아가면` 삭제 후 `고를 만한 서로 다른 방향을 늘리는 학습은`으로 직접 답함. 메모리 벤치마크를 실제 장면으로 재호출하는 378–379는 유지. |

추가 패턴 판정: 번역투·세 줄 이상의 기계적 틀 나열은 심하지 않음. ‘~은 아님’ 계열이 여러 파트 끝에 반복되지만 대부분 중요한 해석 제한이므로 통째로 걷어내면 안 됨. 그림 안내의 ‘보면 됨’도 반복되지만 그림을 읽게 하는 기능이 있으므로, 삭제보다는 315의 ‘그 아래 문장’처럼 대상이 모호한 곳만 구체화할 것.

## 전체 인상

도입 질문부터 보상·결과·출처 한계·사람·실행으로 가는 중심 줄기는 잘 이어짐.
가장 큰 흐름 끊김은 18파트의 뒤늦은 계보·저자 묶음이고, 가장 급한 이해 보완은 supports와 집계 용어임.
AI 티는 말투보다 파트 첫머리의 예고·결산에 남아 있어 그 줄들을 덜어내는 정도로 충분함.

## 최종 재검토: 반영 후 20파트

수정된 `report.md`만 처음부터 다시 읽었음. 원문·원장·outline은 읽지 않았고 본문은 수정하지 않았음. 이 절의 줄 번호는 수정된 413줄 원고 기준임. 앞의 검토에서 이미 해결된 지적을 재수정 대상으로 보지 않음.

판정: 큰 끊김과 필수적인 정의 누락은 해결됐음. 현재 원고는 독립 글로 따라갈 수 있으며, 흐름 때문에 반드시 다시 고쳐야 할 대목은 없음.

### 남은 보완 후보 하나

16파트 324–334줄은 논리적 결론은 이해되지만 사례의 구체성이 약함. `AI 메모리`가 무엇을 시험하는 아이디어인지, 실행에서 어떤 제약 때문에 `만들어볼 가치`까지만 말하는지 한 가지라도 본문에 있으면 인용 그림을 해석하는 힘이 커짐. 현재도 판정과 확증을 구별하는 데 필요한 결론은 적혀 있으므로 차단 사항은 아님. 보완한다면 원문·원장 담당자가 이미 확인한 구체적 제약 한 줄만 넣고, 이 검토의 추측으로 내용을 만들지 말 것.

### 문체·회수 최종 판단

- 새로 반드시 걷어낼 AI 문체 패턴은 발견하지 못했음. 남아 있는 그림 안내·짧은 예고·음슴체 종결은 설명 기능이 있으므로 추가로 일괄 삭제할 이유가 없음.
- CU 집계의 선택 독서 안내는 이제 품질 정의 전체가 아니라 실제 집계 세부에만 걸리므로 앞선 지적은 해결된 것으로 봄. ‘인내 할인’이라는 이름은 남지만 직전에 뒤 답을 덜 읽는다고 풀어 최소 직관을 줌.
- 도입 질문, 현재 검증 상태, 앞으로 확인할 과제가 모두 회수됨. ‘실험 기회’와 ‘입증된 발견’ 사이의 표현 차이도 14–16파트에서 실행·판정·확증을 차례로 분리한 뒤 결론에 이르므로 더는 독자를 놓치는 비약으로 보지 않음.

최종 인상: 학습의 이득을 보여준 뒤 그 점수가 뜻하지 않는 것까지 점차 좁혀 가는 중심 흐름이 유지됨.
초기 검토의 큰 끊김은 해결됐으며, 남은 것은 16파트 사례를 조금 더 구체화할 수 있다는 선택적 보완임.
사소한 어미를 더 고치기보다 현재 흐름을 유지하는 편을 권함.
